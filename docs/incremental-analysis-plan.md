# Android LSP 持久缓存与增量分析改造计划

日期：2026-10-30。用户批准先落档再实施；不推送、不打 tag、不发布远程版本。

## 边界与基线

宿主只提供通用持久目录、身份隔离、生命周期、资源边界与日志。Android Gradle 插件拥有真实变体/模块图，LSP 插件拥有缓存格式、失效、调度与查询聚合。未保存修改保持窗口隔离。已有悬停提示移除改动单独保留，不混入本轮提交。

现状：会话目录退出即删除；KAPT 串行处理模块并重复分析依赖闭包；内容变化推进全局 revision；Kotlin 最多两个惰性 JVM，各堆上限 2 GiB。已有部分跨语言定义，但全项目引用聚合未实现。历史 boostCleaner 25 模块准备 239.7 秒、RSS 约 1.49 GiB；FilesRecovery 6 模块 54.9 秒。新的性能结论须同工具、模型与源码快照对比。

## 缓存契约

持久缓存只存已保存源码的可重建派生产物，私有权限、原子写入，空间和条目有上限。键绑定项目根/目录身份、模块/变体、实际工具与包资源、编译设置、依赖内容和源码摘要，不能用 Git HEAD、mtime 或路径替代。元数据里的临时路径必须校验并重定位。模型 lease、授权和任意 URI 不可缓存复用。

启动检查关闭期间的文件变更，监听丢事件重扫。未保存文本只进入会话临时产物，不能写用户文件或持久缓存。任务捕获一致快照与版本；中断或旧任务不得发布。缓存故障回退重建，不返回已知过时结果。无修改重开避免完整声明准备，但不承诺序列化 JVM/PSI 或零启动等待；两个窗口不能共写可变 JDT 工作区。

首轮采用模块及依赖源码闭包的保守摘要。细粒度 ABI 传播必须覆盖 inline/const、推断类型、默认参数等编译器语义；接口不具备时明确记录门槛，不用正则签名冒充完成。

## 查询与调度契约

定义沿依赖关系解析；引用查询需要反向寻找使用方并由语义后端确认，用真实位置/声明键合并，不能按同名文本构造结果。全项目引用须有完整覆盖或明确未完成状态，不能把当前两个温热会话当成全项目。优先当前模块，有限并行，循环/缺失模型/未生成源码准确报告。

调试日志沿用开关，记录阶段、模块哈希、耗时、缓存命中/失效、队列和计数，不记录源码、符号名、RPC 正文或凭证。

## 验收矩阵

- 冷启动、原样重开、叶子/公共模块修改、换变体/工具、损坏条目、并发窗口、中断写入。
- 未保存覆盖/保存/关闭覆盖，新增/删除/重命名/外部修改及关闭期间变更。
- Java→Java、Java→Kotlin、Kotlin→Java、Kotlin→Kotlin 定义与引用；声明处查询、同名类、非法反向依赖及旧版本取消。
- 记录首次当前模块可用、完整准备、命中/重建模块数、进程树 RSS、重复切换和退出回收。
- 进度真实，键盘跳转/引用选择保持可用，失败可重试。

### C2 基础缓存证据

模块内容摘要缓存、原子压缩条目、损坏/链接拒绝与会话内复用已实现。缓存上限 128 条/256 MiB，单压缩条目 16 MiB、解压 64 MiB；未保存闭包不持久保存。源文件统一捕获，编译器/依赖实际内容入键，合成成员无源码位置的哨兵值不作为跳转位置。
照片恢复真实模型：本轮首次准备+预热 38.8 秒（六模块，其中前期探针已命中一个 Java-only 条目），新进程热启动 5.3 秒，六模块全部命中、编译重建零。两轮 Java→Kotlin 和 Kotlin→Kotlin 定义通过，业务源码哈希不变，stderr 零。热启动 RSS 约 1.02 GiB。此为已有模型的后端探针，不包含 Gradle 模型导入时间。
原生缓存目录两个测试及插件缓存/模块图四个测试通过；完整功能与打包验收仍由 C3–C6 完成。

### C3–C5 实施与已验证范围

- 保守模块失效：只复制/通知产物键变化的模块；按反向依赖标记等待，未受影响 Java 查询继续可用；旧 revision 不发布。保存后的覆盖层经磁盘内容确认提升为持久条目。
- 两个编译作业上限，各 `-Xmx768m`；当前模块优先，源/依赖文件摘要单飞复用。同会话生成请求共享 Promise；跨窗口共享不可变缓存，不共享可变 JVM 工作区。
- Kotlin 后端发现新增/删除/重命名源文件；组件 .3 修复 watch-created 文件被标为 temporary。定义目标删除不返回失效位置。
- 引用按真实依赖根视图查询，由编译器/PSI 确认、JVM 声明键定位 Java 对应项，合并 Java/Kotlin 使用方；规范化 macOS 大小写与 URI 编码，排除私有 stubs，去重。引用查询有 25 秒预算、取消透传，根视图/结果数量有界。
- 私有双模块夹具九项通过：原样热启动零编译、四种定义方向、Java/Kotlin 声明与类的跨模块引用、同名不同符号隔离、无关 Java 模块仍可查询、叶子仅重建一个模块且 dirty 产物不落盘、保存后无需重编译提升缓存、新增未打开源码、重命名映射、删除清理。部分项合并计数。
- 完整夹具十四项通过：含未保存双向签名、补全、当前版本诊断、Kotlin 无效时 Java 语法诊断、切变体保留缓冲区、依赖诊断更新、关闭重开、非法反向依赖拒绝、Kotlin 进程恢复。
- 插件 19 项单测通过，含 RPC 取消和损坏/链接缓存；TS 验收等待当前 URI 的实际类型错误，失败也释放进程，避免把合法的初始空诊断当失败并遗留测试进程。

### 明确限制

首轮缓存粒度为模块及依赖源码闭包；公共模块实现变化仍可能使依赖方重新准备。编译器 ABI 级精确传播、Gradle 模型跨进程缓存、跨窗口全局编译去重和全局内存调度留作后续，不以正则实现替代。当前进程和模型导入仍需初始化。引用范围是已导入 AGP 变体源码图；纯 JVM/组合构建、未生成的 Binding/R/KSP 等仍受原模型能力限制，高级语言构造不宣称全量等同 Android Studio。
