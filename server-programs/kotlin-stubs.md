# Kotlin-to-Java stub bridge

`kotlin-stubs.mjs` is the Java-facing bridge for Kotlin declarations. It compiles the current
Kotlin overlay with the pinned public Kotlin compiler in the fwcd distribution, inspects compiler
output with `javap -c -l`, and emits private Java source stubs for the JDT source path.

The origin map is derived from the compiler `SourceFile`/`LineNumberTable` data. It is not a
same-name text search. `mapOrigin(stubUri, range)` translates a JDT stub line back to the source
Kotlin URI and UTF-16-safe line boundary; the host adapter still owns character-level mapping.

The fwcd distribution does not contain `kotlin-annotation-processing`/KAPT. This bridge therefore
does not execute annotation processors and does not claim kapt compatibility. That is deliberate:
KAPT stubs are an optional later enhancement and must use a separately pinned public compiler
plugin. The current bridge is sufficient for Java-to-Kotlin navigation of compiler-visible classes,
including unsaved Kotlin overlays, without extracting binaries from an IDE.

API:

```js
const { perModuleRoots, mapOrigin } = await generateKotlinStubs({
  model, stateDirectory, java, component, overlays
});
```

`perModuleRoots` contains `stubRoot` for JDT source roots and `classRoot` for generated bytecode.
